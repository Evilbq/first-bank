# First Bank

A polished personal banking website prototype.

## Overview

First Bank is a modern, client-side banking interface that demonstrates a clean and professional user experience for personal banking. It includes account creation, secure login, dashboard overview, card management, and account details — all running entirely in the browser.

## Features

- User registration and login (password hashing with Web Crypto API)
- Persistent accounts using localStorage
- Dashboard with available balance
- Account details view
- Credit and debit card display
- Responsive design optimized for desktop and mobile
- Clean, classic banking aesthetic

## Tech Stack

- HTML5
- CSS3 (modern layout, custom properties, responsive design)
- Vanilla JavaScript
- Web Crypto API for password hashing
- localStorage / sessionStorage for client-side persistence
